# Indian Tourist Analysis 2026 🇮🇳✈️

## Overview
This repository contains a Power BI dashboard designed for **Indian Tourist Analysis** for the year 2026. The dashboard utilizes various DAX measures and data visualizations to provide a comprehensive view of visitor trends, conversion rates, customer satisfaction, and digital marketing performance across different states and regions in India.

## Key Visualizations & Insights

### 1. State & Region-Wise Analysis
* **Visual Type:** Map 
* **Description:** Provides a geographic overview of tourist distribution across the Indian subcontinent.

### 2. Visitor Execution & Date-Wise Analysis
* **Visual Types:** Clustered Column Chart & Stacked Area Chart
* **Description:** 
  * Tracks tourist footfall on specific days (Sunday, Saturday, Friday).
  * Compares daily visitor trends across major states such as **Delhi, Gujarat, and Karnataka**.

### 3. Seasons-Wise Analysis
* **Visual Type:** Clustered Column Chart
* **Description:** Breaks down visits based on regions (Central, East, North, South, and West India) and categorizes them by timing (Morning, Afternoon, Evening).

### 4. Customer Conversion Analysis
* **Visual Type:** Funnel Chart
* **Description:** Visualizes the customer journey and drop-off rates:
  * **Total Visits:** 12.00K
  * **Total Bookings:** 0.60K
  * **Overall Conversion Rate:** ~5%

### 5. Customer & Satisfaction Level Analysis
* **Visual Types:** 100% Stacked Bar Chart & Matrix
* **Description:** 
  * Analyzes customer warranty types (None, Satisfaction, Full Refund, Cancellation) by priority (High, Low, Medium).
  * Details satisfaction levels across various states including West Bengal, Uttar Pradesh, Telangana, Tamil Nadu, Rajasthan, Maharashtra, and Madhya Pradesh.

### 6. Digital Performance Analysis
* **Visual Type:** Matrix Table
* **Description:** Measures the effectiveness of digital acquisition channels across devices.
  * **Channels tracked:** Direct, Email, Facebook, Google Ads, Instagram.
  * **Devices:** Desktop, Mobile, Tablet.
  * **Total Digital Interactions tracked:** 1050 (Instagram and Google Ads driving the highest mobile traffic).

## Technical Details
* **Tool Used:** Microsoft Power BI
* **Key Techniques:** DAX (Data Analysis Expressions) for calculated measures (e.g., Conversion rates, Total Visits, Bookings), Data Modeling, and interactive dashboard design.
